What this console is
Every record here comes from the locked test split — the same holdout RESULTS.md reports numbers against. Nothing is auto-merged: the engine only ever proposes pairs (auto-suggest ≥ 0.92, review 0.75–0.92). A golden record only forms when a named steward clicks approve, and every approve / reject / un-merge is written to the audit log below. This is exactly the two-sided design the sprint plan called for: the model narrows 24.4M possible pairs to ~147k candidates and ranks them, a human keeps the merge authority.
