## 1. GitHub profile  — `aditya-dixitt-profile/`

A self-hosted profile README. No third-party stat service: the stat cards are
SVGs generated from the GitHub GraphQL API by a scheduled Action and committed
into the repo, because `github-readme-stats` is rate-limited in 2026 and shows
as a broken image when it fails.

| file | what it is |
|---|---|
| `README.md` | the profile, positioned for backend/systems |
| `assets/banner.svg` | hand-written, animated |
| `assets/panel-*.svg` | generated by `scripts/build-panels.mjs` |
| `assets/hud-*.svg` | generated by the Action from live API data |
| `scripts/build-panels.mjs` | **all profile content lives in the CONTENT block at the top** |
| `scripts/build-hud.mjs` | GraphQL client + SVG renderer; `--mock` previews layout |
| `.github/workflows/hud.yml` | daily stats sync |
| `.github/workflows/snake.yml` | contribution snake → `output` branch |
| `_previews/` | rendered PNGs, reference only — do not commit |
| `_audit/` | this summary and the profile audit — do not commit |
| `tulya-gitattributes.txt` | **goes in the tulya repo**, renamed `.gitattributes` |

To change profile content: edit the `CONTENT` block in `build-panels.mjs`, run
`node scripts/build-panels.mjs`, commit the redrawn SVGs. Never hand-edit an SVG.

### Two things worth knowing
**Line endings.** Several files were CRLF on disk against LF in the repo, which
made `git diff` report ~1,900 changed lines across files barely touched. Fixed.
If it recurs, `sed -i 's/\r$//'` on the affected files before committing.

**The rename was surgical.** `tulya/build.py` still contains `SAMANVAY` strings
and must keep them — they are the *search* side of find-and-replace pairs in the
rebrand pipeline. `eval/report.py` and `harness.py` keep `"SAMANVAY hybrid"`
because it is a dict key inside the locked holdout artefact; the display label
was changed instead, following the precedent in `build.py:81`.
